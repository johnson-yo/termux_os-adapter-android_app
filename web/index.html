Ownership boundaries

      
    
        
  • Framework / Package route: Framework serves this Adapter page through Package dispatch; that page route is separate from the App API listener.
    • 
        
  • Framework/Core: Framework Core does not own App product workflow. There is no Framework Core /assistant/call alias.
    • 
        
  • Assistant routing: the Adapter owns Assistant route policy; the App provides the event catalog and action envelope.
    • 
        
  • UI ownership: App core settings stay in App; Speech product settings stay in termux-speech; Adapter generic parameters only render fields marked ADAPTER_GENERIC_UI.
    • 
        
  • Capability: trusted Package callers can obtain android.app.api; the Adapter does not implement PCM, RMS, speech, TTS, or audio workflows.
